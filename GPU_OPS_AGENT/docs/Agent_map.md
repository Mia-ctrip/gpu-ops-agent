路线图分成 M1～M9 共 9 个模块。顺序按依赖关系排，每一步做完都有可以验收的结果。分工有三种：

  - 手写：你来写，我只 review。
  - AI：我来写并跑测试，你 review。
  - 你定→AI：你出设计或阈值，我来实现。
